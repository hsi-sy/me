# Hamza Ismael — Personal Portfolio

A simple bilingual Arabic/English personal portfolio, built as a static HTML page.

صفحة شخصية بسيطة باللغتين العربية والإنجليزية، مبنية كملف HTML ثابت.

Live site / الموقع المنشور: https://hamza-portfolio.gentle-cone.workers.dev/

## Files
- `index.html` — the editable website source.
- `hamza-portfolio-source.zip` — the same source packaged for download.

## Run locally
Open `index.html` in a browser. Tajawal is loaded from Google Fonts.
